# SpawnBox

Run a Minecraft server on your own Windows PC without learning how. SpawnBox handles the complicated stuff so parents, teens, and friends can just play.

- Website: https://spawnbox.app
- Community and help: https://discord.gg/qKJnAQhggk
- Videos: https://www.youtube.com/@spawnbox-app

SpawnBox runs your server on [itzg/docker-minecraft-server](https://github.com/itzg/docker-minecraft-server), and we're proud to sponsor it. SpawnBox itself isn't open source; this account is where we contribute back to the projects we build on.
